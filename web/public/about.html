How SUKUNA MD Works

A cyber-grade multi-session WhatsApp bot pairing panel — no console, no QR scanning, just a code.

① Deploy

Head to Deploy Bot, enter your WhatsApp number with country code, pass the quick security check, and receive an 8-character pairing code instantly.

② Link

Open WhatsApp → Settings → Linked Devices → Link a device → Link with phone number instead → enter the code. Your bot goes live in seconds.

③ Manage

Visit Manage Bots any time to see how many bots are paired (numbers are masked for privacy) or to unlink a number you own.

i Notes

  • Pairing codes expire after a few minutes — generate a new one if it fails.
  • Server capacity is limited; if slots show 0, try again later.
  • Paired numbers are never shown in full anywhere on this panel.
